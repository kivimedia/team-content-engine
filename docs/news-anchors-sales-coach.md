# Curated anchors for a sales-coach workspace (Connie Kadansky)

Read by `tce.news.anchors.build_anchor_index` for any workspace whose lane profile
is `sales_coach` (TCE_WORKSPACE_LANE_PROFILES). For those workspaces this file
REPLACES `news-anchors.md`, and the anchors derived from this box's settings and
repos (Ziv's vendors, model ids, Kivi repos) are not built at all. Owner workspaces
never read this file.

Format is the same as `news-anchors.md`: `## <anchor kind>` then `- <term>`.
Matching is whole-word on the normalised title and summary, so plurals are listed
on purpose ("contract talk" does not match "contract talks").

`client_solution` is a strong kind: one hit is enough. Here it means a negotiation
a rep can learn from (a deal, a contract, a price fight) or her own subject (sales
calls, prospecting). `problem_pattern` needs two independent hits, so it holds the
broad deal words that only count together.

Never add a bare "negotiation", "negotiations", "talks" or "deal" as a strong
anchor: "ceasefire negotiations", "trade talks" and "peace deal" are war and
politics headlines, which never belong in her lane. They live in `problem_pattern`
and count only next to a second hit. Never add a bare place or a party name.
